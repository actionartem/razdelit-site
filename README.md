# Разделить — сайт и демонстрация

https://razdelit.ru/

Статический лендинг и интерактивный прототип. Демонстрационная оплата не проводит денежных операций. Форма отправляет заявки автору через Telegram-бота @razdelit_bot. Успех показывается после подтверждения Telegram; при ошибке поля сохраняются.

GitHub Actions публикует сайт в GitHub Pages при изменении ветки main. Исходные документы проекта в этот репозиторий не входят.

Для обновления главной страницы редактируйте landing/index.html, landing/styles.css и landing/script.js. Сборка `node build.mjs` создаёт `_site` и исправляет пути для главной страницы. Открытие `/prototype/` показывает весь прототип. Для публикации не нужны секреты.

Обработчик заявок описан в [contact-api/README.md](contact-api/README.md). Его код не входит в артефакт GitHub Pages. Токен Telegram хранится только в закрытом файле на сервере; не добавляйте его в сайт, коммиты или workflow.
